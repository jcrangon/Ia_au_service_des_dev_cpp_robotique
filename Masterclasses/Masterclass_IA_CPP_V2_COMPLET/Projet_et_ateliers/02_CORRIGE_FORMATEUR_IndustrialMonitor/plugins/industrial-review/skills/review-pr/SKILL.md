# Revue de Pull Request industrielle
1. Vérifier le commit, la branche et les exigences applicables.
2. Relire le diff ; classer faits, hypothèses et résultats observés.
3. Vérifier les tests de frontières et les rapports Clang / CTest / CI.
4. Rechercher les risques de régression et les permissions excessives.
5. Livrer une décision ACCEPT/MODIFY/REJECT justifiée.
Aucun avis IA ne peut remplacer l'approbation d'un responsable compétent.
