# Industrial safety requirements — exercise only
REQ-01: Movement is forbidden if the sensor is unhealthy.
REQ-02: Movement is forbidden if age_ms > 200.
REQ-03: Movement is forbidden if either numeric input is NaN or infinite.
REQ-04: Movement requires distance_m > 2 * speed_mps, with speed_mps >= 0.
REQ-05: Report missing tests and do not approve software for production use.
